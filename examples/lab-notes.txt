The OpenSCAD lab — specimen notes
==================================

Every model in examples/ is an invented, generic
household object. Nothing here is modelled on any
real organisation, event, or person's belongings.

  primitives.scad   cube, sphere, cylinder side by side;
                    the sphere is centred on the origin,
                    the cylinder is tapered (r1 != r2)
                    and asks for $fn = 48.
  transforms.scad   rotate, translate, scale, mirror and
                    color applied to one repeated cube;
                    a mirrored sphere pair at the end.
  booleans.scad     a 60 x 40 x 10 plate with two r=3
                    bolt holes (cutters run z=-1..11, one
                    unit proud on both faces), and an
                    intersection specimen: two r=12
                    spheres fused, clipped by a 10-thick
                    slab.
  rounded.scad      a hull() plate from four r=6 corner
                    posts (60 x 40 footprint, 8 tall) and
                    a minkowski() block: 20 x 12 x 6 cube
                    plus r=2 sphere = 24 x 16 x 10 overall.
  project-box.scad  the parametric star. Default outside
                    80 x 55 x 30, wall 2.4, lid printed
                    beside it at x = width + 10. The rim is
                    the inside opening minus 0.4 clearance
                    per side (echo reports: inside
                    75.2 x 50.2, rim 74.4 x 49.4).
  plant-pot.scad    rotate_extrude profile: top r=40,
                    base r=30, height 70, wall 2.4, floor
                    hole r=8. One closed polygon, so one
                    watertight solid.
  name-tag.scad     76 x 28 x 3 tag, hanging hole r=3 at
                    one end, the name "Ada" in Liberation
                    Sans Bold at size 14 standing 1.2 proud
                    of the face. Change it with -D.
  bracket.scad      L bracket: 50 legs, 30 wide, 4 thick,
                    two r=2.6 holes per leg.
  flat.scad         a pentagon prism twisted 90 degrees
                    over a height of 30 (profile centred
                    on the origin first — see addendum),
                    and a 30 x 20 plate rounded by
                    offset(r=3) to 36 x 26, extruded 4.
  fn-demo.scad      a single r=20 sphere; fn is a
                    variable so -D fn=... drives the
                    smoothness/timing comparison.
  broken.scad       FAILURE FIXTURE. `widht` is a typo
                    for `width`: OpenSCAD warns twice,
                    the size becomes undef, and it
                    exports a fallback 1 x 1 x 1 cube —
                    exit code 0. --hardwarnings stops
                    it with exit code 1 instead.
  syntax-error.scad FAILURE FIXTURE. A missing bracket:
                    a real parse ERROR, exit code 1, and
                    no output at all.

Outputs (STL/PNG) are build products, regenerated by
the transcript commands; they live in the build
scratch (openscad-build/out), not in this repo,
except the numbers quoted from them in the chapters.

Addendum, written after the first captures: flat.scad
originally drew its pentagon off-centre (translate
inside the extrude) and the measured bounding box
(y from -26) showed the twist swinging the profile
around the 2D origin. The specimen was rewritten to
the centre-first pattern and recaptured; chapter 7
states the rule on that evidence.
